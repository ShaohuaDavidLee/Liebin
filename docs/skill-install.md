# 列宾 Skill · 安装与使用

这是列宾的完整技能安装包，不是一次设计任务的资料包。

## 安装

- 工具支持「导入技能 / 上传 Skill」：选择原始的 liebin-skill.zip，按工具提示完成导入并启用。如果入口要求文件夹，请先解压并选择其中的 liebin 文件夹。
- 工具使用本地 skills 目录：将解压出的整个 liebin 文件夹放进该工具指定的技能目录，保持 SKILL.md、references、scripts、assets 的相对位置；按工具说明刷新技能或新建对话。
- WorkBuddy：从「添加技能 → 上传技能」导入。其他工具的入口和目录以各自文档为准。

不要只上传 SKILL.md，也不要把整个 ZIP 当作普通聊天附件来代替技能安装。

## 开始第一个任务

安装并启用后，对智能体说：

> 请使用列宾（liebin）Skill，帮我的产品定设计方向。先给我三版样张，等我选择和反馈之后，再生成 DESIGN.md。下面是我的产品内容和参考。

随后提供产品叫什么、给谁用、真实文案，以及可选的参考网址或截图。也可以在列宾落地页填写表单，复制任务内容或下载 liebin-brief.zip，并将任务资料交给已安装列宾的智能体。

## 执行环境

列宾需要智能体能够读取技能和参考资料、生成与保存 HTML 和 Markdown 文件；输入网址需要网页访问能力，输入截图需要图片理解能力。

样张辅助脚本 scripts/proof.mjs 使用 Node.js 18+。浏览器测量和 scripts/verify-page.mjs 验收需要浏览器及相应工具；不可用时，SKILL.md 提供手动模板和人工对照路径。能导入技能包不等于所有自动检查都可执行，具体能力由所用工具及其权限决定。

## 更新

更新列宾时重新下载技能包，使用智能体提供的更新或替换方式；如果出现同名技能提示，按其说明处理。安装包只包含可复用的技能文件，不包含你在落地页填写的任务内容或上传的参考图。
